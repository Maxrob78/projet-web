🖥️ Présentation du Conteneur Média

Ce système est une interface d'overlay dynamique conçue pour l'affichage de contenus multimédias hybrides. Il gère l'empilement intelligent des couches selon les fichiers fournis.

Couche Fond : Conteneur fixed plein écran avec gestion du rafraîchissement au redimensionnement.
Couche Visuelle : Rendu adaptatif (Image ou Vidéo) avec calcul de ratio pixel-parfait via ajusterTailleMedia.
Couche Textuelle : Titre "Impact" auto-centré si aucun visuel n'est présent via la classe title-only.

💡 Guide de fonctionnement

⏱️ Gestion de la Durée

auto : Se base sur la fin de la vidéo ou 10s pour une image.
inf : Boucle infinie.
Nombre : Arrêt forcé en millisecondes.

🎵 Mode Mixte & Audio

Si Image + Vidéo : l'image s'affiche tandis que la vidéo sert de piste sonore (le son est maintenu même si l'image échoue).

⚡ Vitesse & Volume

Contrôle du playbackRate (0.5x à 4x) et du gain audio via l'API HTML5, validés par le script avant chaque lancement.

🖱️ Interaction UI

Le bouton "Lancer" s'active dynamiquement dès qu'une source (Texte, Image ou Vidéo) est détectée dans la configuration.

⚙️ Analyse technique du système

1. Validation (validateConfig)

Détecte l'audio par extension, sécurise les valeurs numériques et nettoie les entrées textuelles avant le rendu.

2. Moteur de Rendu (mediaStart)

Gère les promesses play() pour contrer le blocage "Autoplay" en passant en muet si nécessaire.

3. Cycle de Vie (mediaStop)

Assure l'arrêt total : coupe le son, vide les src pour la RAM, et annule les timeouts.

4. UI Réactive

Utilise URL.createObjectURL pour prévisualiser les fichiers locaux sans upload, avec un système de reset complet du DOM.

🛠️ Section Debug (Console F12)

Le système logue ses actions en temps réel. Appuyez sur F12 pour voir :

  • 🚀 Lancement : Vérifiez le groupe "Validation Media Pro" pour voir les ajustements automatiques.
  • ⚠️ Erreurs : Le script affiche des alertes si une image est introuvable ou si l'autoplay est bloqué.
  • 📏 Resize : Les logs "[RESIZE]" confirment les dimensions exactes appliquées au média.
