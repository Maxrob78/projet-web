# 🌐 Projet de Programmation WEB - XT1205-DEV

Ce projet consiste en la réalisation d'un **site vitrine** pour le département d'Informatique de l'**EFREI** (Paris Panthéon-Assas Université). Il a été développé dans le cadre du module XT1205-DEV pour l'année universitaire 2025-2026.

## 📋 Présentation du Projet
L'objectif est de concevoir un site Web interactif, responsive et modulaire mettant en avant les formations et l'équipe du département.

### Contraintes Techniques (Strictes)
Conformément aux consignes du projet :
* **Technologies :** HTML5, CSS3, JavaScript et PHP.
* **Zéro Framework :** L'utilisation de frameworks ou de bibliothèques externes est strictement interdite.
* **Standards :** Toutes les pages sont valides aux normes W3C.
* **Versioning :** Projet géré intégralement via Git avec un historique de commits complet.

---

## 🚀 Fonctionnalités Clés

### 💻 Front-end & Design
* **Design Responsive :** Adaptation complète sur tous les terminaux via les media queries et la gestion du viewport.
* **Interactivité JS :** Animations CSS/JS, gestion de l'agenda, menus interactifs et validation dynamique des formulaires.
* **Navigation :** Arborescence fluide limitée à 2 niveaux (Accueil > Pages principales > Sous-pages).

### 🛠️ Back-end & PHP
* **Modularité :** Découpage des pages en modules PHP (`header.php`, `footer.php`, `navigation.php`) pour optimiser la maintenance.
* **Traitement de Données :** Gestion du formulaire de contact en PHP via la méthode `$_POST` avec messages de succès personnalisés.
* **Contenu Dynamique :** Affichage des membres de l'équipe et des formations à partir de tableaux PHP ou de fichiers JSON.

---

## 📂 Structure du Site
Le site est articulé autour de 4 pages principales:
1.  **Accueil :** Présentation du département et carrousel d'actualités.
2.  **Cours et Formations :** Catalogue détaillé des enseignements.
3.  **Équipe Enseignante :** Annuaire dynamique des intervenants.
4.  **Contact / À Propos :** Formulaire de contact et présentation des membres du groupe projet.

---

## 🛠️ Installation Locale

1.  **Cloner le dépôt :**
    ```bash
    git clone [https://github.com/Maxrob78/projet-web.git](https://github.com/Maxrob78/projet-web.git)
    ```
2.  **Lancer un serveur PHP :**
    Utilisez un environnement type XAMPP, WAMP, MAMP ou lancez le serveur intégré :
    ```bash
    php -S localhost:8000
    ```
3.  **Accéder au site :** Ouvrez votre navigateur sur `http://localhost:8000`.
